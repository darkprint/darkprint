# Source documents

The three files in this folder are the Italian design notes DarkPrint was first built from: the
data model (`darkprint-design.md`), positioning and onboarding
(`darkprint-onboarding-positioning.md`) and the first draft of the vocabulary
(`darkprint-ontology-v0.1.md`). Code comments cite their section numbers as "doc 1 §4" and
so on. They are kept for that reason only. They carry no authority: where one of them and the
tree disagree, the tree is right, and `docs/ARCHITECTURE.md` is the description to trust.
