fact here was re-derived from the code independently of that inventory. The full field-level

| Prohibition | What a card refuses to receive, in two fields that are not the same promise. `cannot` holds `data-type` term ids ONLY and the resolver checks every edge against it (`bundle/prohibition-violated`, error). `willNot` holds the author's own prose undertakings and is read by nothing. | Draft bundle | What `darkprint import` synthesises from an Attractor pipeline: a `topology.dot`, one card per node at version `0.1.0`, and a stub manifest.
